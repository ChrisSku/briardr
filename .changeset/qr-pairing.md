**Pair a device by scanning a QR code.** "Add a device" in Settings → Devices and `briardr pair` (in a terminal) show a QR code beside the one-time code. A camera opens Briardr from it with the code filled in; the code travels in the link's fragment, which browsers send to no server or proxy, and is taken out of the address once read. On an iPhone or iPad the pairing screen reminds you to add Briardr to the Home Screen first, since the Home Screen app signs in separately.
