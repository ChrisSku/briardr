**Pair a device by scanning a QR code.** `briardr pair` (in a terminal) and Settings → Devices → Add a device show a QR code beside the one-time code. The new device's camera opens Briardr with the code filled in, and you still name the device and choose Sign in. The code travels after the link's `#`, which browsers send to no server or proxy, Briardr takes it out of the address once it has read it, and it still works once and expires after ten minutes. From the host itself (`localhost`), Settings shows the address `briardr pair` prints, which other devices can open. On an iPhone or iPad the pairing screen reminds you to add Briardr to the Home Screen first, since the Home Screen app signs in separately.
