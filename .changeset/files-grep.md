**Files can search inside files.** The search in Files finds files by name, as before, or, with Contents, the lines that contain what you type (as plain text, in any case). A line opens its file there, picked, ready to add to a prompt. The search reads text files up to 1 MB and, in a Git repository, leaves out what `.gitignore` names (dependencies, build output).
