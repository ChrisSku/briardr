**Changes can show everything since the branch the work started from, not only what isn't committed yet.** When a stream's branch has commits of its own, Changes offers "Since main" beside "Uncommitted": the branch's commits and its uncommitted work as one set of changes, compared with the newest commit the branch shares with the repository's main branch (the one `origin/HEAD` names, else `main` or `master`). Work an agent has already committed no longer drops out of review. Reviewed marks, and the lines comments mark, are kept apart for the two views.
