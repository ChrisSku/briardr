**Changes can show everything since the branch the work started from.** When a stream's branch has commits of its own, Changes offers "Since main" (or whatever the repository's main branch is) beside "Uncommitted": the branch's commits and the uncommitted work as one set of changes. Until now, work an agent had already committed was gone from review. "Reviewed" marks are kept separately for the two views.
